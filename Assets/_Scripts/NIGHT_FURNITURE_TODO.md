# 夜の家具編集ターン — 進捗リスト

夜になったら家具を入れ替える編集ターンにする機能の TODO。
最初は **P キー**で開く → 最終的に**室内PCの操作**で開くように移行する。
家具編集は**夜のターンのみ**使用可能。

## ステータス凡例
- 🔲 未制作
- 🟡 進行中
- ✅ 完成

## フェーズ2: 家具の編集機能（ローカル先行） ✅
| 状態 | 項目 | 内容 |
|---|---|---|
| ✅ | 家具データ定義 | `FurnitureItem`（prefab / id / 名前 / 仮ブロック / コスト枠） |
| ✅ | 家具カタログUI | 下部バー＋数字キー選択、選択中ハイライト（ランタイム生成） |
| ✅ | 家具の設置 | カメラ中央レイ→ゴーストプレビュー→左クリックで設置 |
| 🟡 | 設置位置のスナップ/判定 | 現状は自由配置（床に底面を合わせる）。グリッドは未実装（未決定事項） |
| 🟡 | 家具の移動・回転 | 回転=R/ホイール ✅。既設置の「移動（つかむ）」は未実装 |
| ✅ | 家具の撤去 | 右クリックで見ている家具を削除 |

> 仮ブロック（色付きCube）で即動作。`FurnitureItem.prefab` にPrefabを入れると見た目が差し替わる。
> ※ 設置はまだ**ローカルのみ**（マルチ同期はフェーズ3）。

## まず着手する範囲（最初のゴール）
> **「夜にPキーで家具モードが開き、家具を1つ設置できて、全員に同期される」** まで。

最短の達成順：
1. `DayManager.IsNight` 追加（フェーズ1）
2. `FurnitureEditController` でPキー開閉（夜限定）（フェーズ1）
3. 家具1種を設置できる最小実装（フェーズ2）
4. 設置物のNetworkObject同期（フェーズ3）

ここまで出来たら、家具の種類追加 → PC操作化（フェーズ4）へ進む。
