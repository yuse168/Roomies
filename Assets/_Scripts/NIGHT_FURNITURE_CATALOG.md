## 効果の実装方式（メモ）
効果は大きく3タイプに分けると実装しやすい：

1. **パッシブ常時系**（速度+%, パッシブ収入, スロット確率）
   → 設置中フラグを集計する `FurnitureEffectManager` を作り、各システムが参照
2. **インタラクト系**（触ると一定時間バフ：コーヒー・エナドリ）
   → `PlayerInteract` で触れたら `PlayerBuff`(時間付き) を付与
3. **朝/晩トリガー系**（毎朝の自動収入・寝るとバフ）
   → `DayManager` の朝/夜イベントから設置家具を走査して適用

## まず作る順（おすすめ）
1. `FurnitureEffectManager`（設置中家具の効果を集計する土台）
2. **パッシブ収入系**：`piggy_bank` / `vending_machine`（朝の自動収入＝既存の口座と相性◎）
3. **移動バフ系**：`coffee_maker` / `energy_drink_fridge`（触るとバフ＝分かりやすい）
4. **ネタ枠**：`trampoline` / `disco_ball`（パーティー感）
