# Plan: DeliveryZone にノーマル/レア別プレハブ対応

## 概要
`DeliveryZone` がノーマル用とレア用の別々の箱プレハブを指定できるようにし、
アイテムごとの重さ・見た目などの設定を独立して行えるようにする。

## 変更点

### `DeliveryZone.cs`
1. フィールド変更:
   - 削除: `private NetworkObject deliveryBoxPrefab`
   - 追加: `private NetworkObject normalBoxPrefab` (通常用)
   - 追加: `private NetworkObject rareBoxPrefab` (レア用、未設定時は `normalBoxPrefab` に fallback)

2. `SpawnNewBox()` 修正:
   - 先にレア判定 (`Random.Range(0, 100) < rarePercent`) を行う
   - レアなら `rareBoxPrefab` (なければ `normalBoxPrefab`)、通常なら `normalBoxPrefab` を選択
   - 選択したプレハブでスポーン
   - `DeliveryItem` が見つかれば `SetRare(isRare)` を呼ぶ
   - エラーログの文言を更新

### `DeliveryItem.cs`
- 削除: `normalVisual`, `rareVisual` フィールド（別プレハブで見た目は完結するため不要）
- 削除: `UpdateVisual()` メソッド
- 削除: `OnRareChanged()` メソッド
- 削除: `OnNetworkSpawn()` / `OnNetworkDespawn()`（isRareItem の ValueChanged 購読を管理するだけだったため）
- 維持: `isRareItem` NetworkVariable, `SetRare()`, `IsRareItem()`（報酬判定に必要）
- 維持: `penaltyMoney`, `groundTag`, `isBroken`, `ownerZone`, `OnCollisionEnter()`（レアペナルティに必要）

### `DeliveryButton.cs`
- `[Rpc(SendTo.NotServer)]` → `[ClientRpc]` に修正（クライアントフィードバック用）
- `PressButton(playerEarning)` が null 時に警告ログを追加
- 失敗/成功時に ClientRpc でメッセージを送信

## プレハブ設定注意点
- 箱プレハブの Mesh Collider は `Convex` = true にする必要がある（Concave Mesh + Dynamic Rigidbody は不可）
- `rareBoxPrefab` として使うプレハブには `DeliveryItem` コンポーネントを子に付けること（ペナルティ衝突判定に必要）
- ノーマル用プレハブには `DeliveryItem` は不要（無視される）

## バグ修正: 納品ボタンが反応しない問題

### 原因
1. `DeliveryZone.normalBoxPrefab` 未設定 → 箱がスポーンされず `HasBox()` が false
2. `PressButtonServerRpc` 内のエラーメッセージ (`Debug.Log`) がサーバー側のみ出力されるため、クライアントからは何も起きていないように見える
3. `ShowResultClientRpc` に誤って `[Rpc(SendTo.NotServer)]` を使用（他コードでは `[ClientRpc]` が使われている）

### 修正内容 (DeliveryButton.cs)
1. `[Rpc(SendTo.NotServer)]` → `[ClientRpc]` に修正（他スクリプトと統一）
2. `PressButton(playerEarning)` が null 時に警告ログを追加（無反応の原因特定用）

## 根本原因分析: 箱がゾーンに入っても検知されない

### 原因
`DeliveryZone.OnTriggerEnter()` での検知条件は2つ：

```csharp
if (!other.CompareTag("DeliveryBox")) return;
other.GetComponent<NetworkObject>()
```

**最も可能性が高い原因**: 新しい箱プレハブ(`normalBoxPrefab`)の Collider に **`DeliveryBox` タグが設定されていない**。

### 確認すべきこと
1. 箱プレハブの Collider がある GameObject の Tag が `DeliveryBox` になっているか
2. `NetworkObject` コンポーネントが Collider と同じ GameObject（または親）にあるか
