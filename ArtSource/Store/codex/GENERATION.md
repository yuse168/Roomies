# 制作設定

内蔵 image_gen を使い、24枚を1枚ずつ生成。出力を指定寸法のPNGにリサイズ。生成元は assets_manifest.json に記録。

共通プロンプト：fictional Japanese CORNER STORE / production-ready flat game texture / sophisticated rounded friendly flat vector-like illustration / bold readable silhouette / smooth curved outlines / restrained detail / matte solid fills / no low poly / coral #E06A52, dark coral #A8432F, cream #F4ECDA, ink #2A2230 / no prices, no real company or product names, logos, or recognizable trade dress.

各画像の主題・日本語文字・寸法・透明指定は assets_manifest.json の subject / text / width / height / transparent を使用。ラベルは平面印刷図案、ポスターとのぼりは価格なし。ロゴは丸いさんご色タイル、クリームのL字と四芒星、文字なし。透明指定画像は透明背景で生成。

画像生成のため、色番号はプロンプト指定色を基準とした近似色・アンチエイリアスを含みます。
