# コンビニ（CORNER STORE）の絵の依頼（2026/11/24）

Roomies の町のコンビニを作り込んでいます（ゆせさんの依頼「コンビニを深堀り。ローポリをやめて」）。
いまの商品のラベルや看板は、色の帯だけです。描いた絵が入ると、ぐっと店らしくなります。

## 決まり

- **オリジナルの店**です。実在のコンビニ・メーカー・商品の名前、ロゴ、色の組み合わせ（緑と青、青と白、オレンジと緑と赤 など）はまねしない。
- 文字は日本語のひらがな・カタカナ中心で短く（読めなくてもよい飾りの文字でも可）。実在の商品名は書かない。
- 店の色：さんご色 `#E06A52`、濃いさんご色 `#A8432F`、クリーム `#F4ECDA`、墨色 `#2A2230`。
- 輪郭のはっきりした、やわらかいフラットな絵（カジノの絵ほど描き込まない）。
- PNG。透明が要る物は、角の外を透明に。
