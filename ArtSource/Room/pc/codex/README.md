## 配置と確認

画像内に文字はありません。アプリ名・時刻・残高・OS名はゲーム側で重ねてください。アイコンの外側とロゴの背景はアルファ透過です。壁紙は左上と下端の情報量を抑えています。モニター待ち受けは静止画像のため、画像内のアイコンは操作要素ではありません。

参考はart_rules.mdと指定された4枚の現行画面。色のHEXは目安として用い、現行UIの黒・紫・クリーム、家具の黄・緑に合わせています。ゲーム内の発光・露出・縮小表示の最終確認は未実施です。

生成プロンプトはprompts.jsonに保存。実在ブランド・既存OSの模倣を避け、丸いマットな立体表現を指定しています。
